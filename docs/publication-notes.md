# Public repository scope

Prepared on 2026-11-08 for the product owner's requested public GitHub upload.
The repository is a local research prototype; financial and final product
acceptance remain pending.

## Included

- Python source, neutral test fixtures and dependency/configuration examples.
- English requirements, architecture, actual evaluation records and reproduction
  instructions, plus the project language policy.
- Official source metadata and necessary short evidence/candidate review records.
- Actual app screenshots with visible pending-review and historical-score labels.

## Kept local

- Original annual-report PDFs, full page text, indexes, local evaluation outputs
  and databases.
- Actual credentials, `.env`, private keys, virtual environments and caches.
- The original product-owner plan and initial agent bootstrap prompt. The public
  product requirements are documented in `PRD.md`.
- Exact private execution transcripts retained under the ignored
  `data/processed/private-execution-records-before-publication/` directory.

Machine-specific personal paths in published stage reports were generalized for
sharing. Placeholders such as `<project-root>`, `<user-home>` and
`<temporary-source-copy>` require local substitution. Original observed test
counts, outcomes and limitations were preserved; path-generalized commands are
not represented as a new execution. README uses portable first-run commands.

Public source metadata and short quotations identify evidence; they do not grant
a license to redistribute complete annual reports or imply company endorsement.
The raw reports must be obtained independently from authorized official sources.

No financial candidate, comparison pair, gold answer or human response rating is
approved by publication. The initial public release recorded 446 passing tests;
Stage 11 records 490 passing tests and an empty real-data reviewed-fact store.
Stage 12 records 575 passing tests and the separate reviewed KPI lookup, with no
actual financial value released. Its screenshot shows the genuine pending state.
The forty-case development results retain their original recorded date
and null human correctness scores. See `EVALUATION.md` and the acceptance guides
for limitations and remaining work.
